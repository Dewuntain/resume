Система компьютерного зрения для подсчёта и измерения объектов на конвейере

Задача
  • Реализовать систему для подсчёта и измерения размеров объектов на конвейере в реальном времени.
Ограничения
  • Размещение и параметры камеры не известны заранее.
  • Наличие засветов на видеопотоке.
  • Возможные перебои с доступом к общей БД.
  • Искажённая перспектива получаемого видеопотока.
Решение
  • Реализация сохранения результатов в локальной БД при перебоях с доступом к общей БД и перенос после восстановления.
  • Реализация таблицы масштабов для определения размеров объектов с учётом искажённой перспективы видеопотока.
  • Определение пороговых значений для исключения влияния засветов.
Результат
  • Перевод учёта с ежеквартального на учёт в реальном времени.
  • Обеспечение точности 98,6% при сравнении с реальными размерами объектов.
  • Система оповещений при перебоях с доступом к общей БД и отсутствии видеопотока.

Поиск по документам с векторной индексацией

Задача
  • Реализовать чат для получения ответов с информацией из внутренних документов.
Ограничения
  • Запрет на использование внешних LLM и облачных индексов.
  • CPU — единственный вычислительный компонент.
  • Нет единого формата оформления документов.
  • Обязательное использование n8n для реализации пайплайнов.
Решение
  • Развёртывание локальной LLM и Qdrant для векторной индексации.
  • Реализация приложения для локального хранения документов, эмбеддингов и разбиения на чанки.
  • Реализация системы очистки документов перед индексацией.
  • Реализация пайплайна индексации и обновления документов через n8n.
  • Реализация пайплайна поиска информации и выдачи ответов через n8n.
  • Реализация веб-интерфейса поиска на FastAPI.
Результат
  • Данные не покидают контур компании.
  • Время поиска сократилось с 30 до 2 минут.
  • Поток обращений в отдел документации −40%.
  • Документы автоматически индексируются и обновляются при загрузке в хранилище.
  • API для использования с другими приложениями.
